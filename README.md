## 📘 Project Overview

**The Sugar Free Cookbook** is a responsive, accessible web platform designed to support individuals managing diabetes. It offers curated recipes that are sugar-free, nutritious, and tailored for a healthier lifestyle. With a modern interface and interactive features like favoriting meals and categorizing dishes, the platform provides a seamless experience across devices.

> 🧾 _A project submitted in partial fulfilment of the requirements for the Vocational Education Course —_  
**“Building Responsive and Accessible Web Interfaces (AD2551-1)”**

---

## 🌟 Features

- 🍳 **Categorized Recipes**: Browse healthy options by **Breakfast**, **Lunch**, **Dinner**, and **Beverages**.
- ❤️ **Favorite Recipes**: Add and manage your personalized favorite recipes.
- 🖥️ **Responsive UI**: Seamless experience across desktops, tablets, and mobile.
- ♿ **Accessible Design**: Designed with accessibility best practices.
- 🔐 **Login/Sign-Up**: Simple local user management using browser storage.
